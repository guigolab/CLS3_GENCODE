# Representative TSS sets, by biotype:

### 1. Protein coding TSS:
Generated 48,420 TSSs from the list of GENCODE v47 protein-coding transcripts (89,832 transcripts, 19,744 genes).

### 2. LncRNA TSS:
Generated 20,340 TSSs from the list of GENCODE v27 lncRNAs (26,709 transcripts, 14,680 genes).

### 3. Decoy TSS:
Generated 60,143 TSSs from the list of decoy models (85,283 transcripts, 17,223 genes). Decoy transcripts were generated in a strand-agnostic manner and therefore duplicated on both strands prior to representative TSS set generation, resulting in a doubling of the total decoy transcript count.

### 4. Novel TSS (all novel transcripts):
Generated 52,345 TSSs from the entirety of transcripts added or extended in GENCODE v47 due to CLS experiment (149,392 transcripts, 26,946 genes). Below the biotype dissection:
These include the below described novel protein-coding (4.a) and novel lncRNA transcripts (4.b).

A. **novel protein-coding transcripts**:
A total of 198 novel TSSs associated to 371 novel protein-coding transcripts (141 genes).

B. **novel lncRNAs**:
A total of 52,137 novel TSSs associated to 149,010 novel lncRNA transcripts (26,794 genes). 

C. **CLS transcripts**
Representative set of 11,443 TSSs obtained from 19,111 disjoint CLS transcripts (8,392 genes, intergenic with respect to GENCODE v27).
